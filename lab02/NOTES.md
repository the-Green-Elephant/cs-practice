Рабочая папка - файлы проекта, которые находятся на устройстве, относятся к текущему проекту и с которыми я сейчас работаю.

Индекс - область в Git, куда добавляются изменения для коммита.

Коммит - сохранённый набор изменений в истории репозитория.


Git - программа для ведения истории изменений, которая работает с репозиторием

GitHub - сайт для хранения, публикации и совместной работы над Git-репозиториями


Использованные комманды:
git status - показывает состояние рабочей папки и индекса
git diff - показывает изменения в рабочей папке, которые еще не добавлены в индекс
git diff --staged - показывает изменения, добавленные в индекс и подготовленные к коммиту

Ветки
Ветка - отдельная линия разработки, которая указывает на последовательность коммитов
При ноыом коммите ветка начинает указывать на этот новый коммит
Слияние объединяет изменения из обоих веток и создаёт общий результат
