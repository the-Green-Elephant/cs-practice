Рабочая папка - файлы проекта, которые находятся на устройстве, относятся к текущему проекту и с которыми я сейчас работаю.

Индекс - область в Git, куда добавляются изменения для коммита.

Коммит - сохранённый набор изменений в истории репозитория.


Git - программа для ведения истории изменений, которая работает с репозиторием

GitHub - сайт для хранения, публикации и совместной работы над Git-репозиториями
